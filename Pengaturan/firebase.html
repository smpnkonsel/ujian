Konfigurasi Firebase

Lima project Firebase yang dipakai aplikasi, dan peran masing-masing dalam alur CBT.

Konfigurasi project ditulis di satu tempat: assets/js/firebase-pusat.js. Semua halaman admin dan halaman siswa membaca dari berkas itu, jadi tidak ada lagi pengaturan yang tersimpan terpisah di browser. Untuk mengganti project, ubah berkas tersebut lalu unggah ulang. Keamanan data ditentukan oleh Security Rules di tiap project Firebase.
